# Chocolate Sales Data Analysis
# Data Source

The dataset was obtained from Kaggle – Chocolate Sales Dataset.

# 1. Objective

Analyze international chocolate sales to understand customer behavior, identify top-selling products, and examine the relationship between price and sales volume.

# 2. Methodology

An exploratory data analysis (EDA) was conducted using chocolate sales data. The process included:

Data cleaning and preprocessing
Trend and correlation analysis
Data visualization

The goal was to identify sales patterns, product performance, and market trends to support business decisions.

# 3. Tools and Technologies
Python
Visual Studio Code
Plotly Express
pandas
NumPy

# 4. Key Findings
Revenue and Market Trends

Revenue contribution was similar across countries (15–18%).

Australia generated the highest revenue; New Zealand the lowest.

Global sales peaked in June after declining earlier in the year.

Product Performance

# Top-performing products:

Smooth Silky Salty

50% Dark Bites

White Choc

Peanut Butter Cubes

Eclairs

Customer preferences varied by country. Some high-revenue products, such as White Choc, had lower sales volume, suggesting higher profitability.

# Price Sensitivity
All markets showed a negative correlation between price and sales volume.

Australia, Canada, and the USA were the most price-sensitive.

India showed more stable demand despite price changes.
